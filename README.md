# Git Fundamentals · Practice Repository

A small learning repository for experimenting with commits, branches, and merges. The useful artifact is the version history and workflow practice rather than an application.

**Git · JavaScript**

[Portfolio](https://github.com/kuvlay)

## Repository contents

| File | Purpose |
| --- | --- |
| `hello.js` | Small JavaScript practice snippet |
| `test.js` | Prints a message to the console |
| `docs/original-notes.md` | Original notes from the Git exercise |

## Explore locally

```bash
git clone https://github.com/kuvlay/mastering-git.git
cd mastering-git
git log --oneline --graph --all
```

With Node.js installed, the simple console example can be run using:

```bash
node test.js
```

No package installation, environment configuration, or backend is needed.

## Scope and status

`test.js` is a console demonstration, not an assertion-based test suite. `hello.js` currently references undefined identifiers and is an unfinished exercise. This repository should be presented as Git practice rather than a completed software product.
